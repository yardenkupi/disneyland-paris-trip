# הטיול הקסום שלנו · דיסנילנד פריז

אפליקציית ווב משפחתית ופרטית לתכנון טיול לדיסנילנד פריז ולפריז (מאי 2027).
האפליקציה לא קשורה ל-Disney.

## מה יש בה
- **עכשיו**: שעות הפתיחה ו-Extra Magic Time להיום, המתקנים עם התור הקצר ביותר שמתאימים לבנות, מופעים, מתקנים סגורים ומזג אוויר.
- **מפה**: כל המתקנים, המסעדות, המופעים, המלונות והנקודות בפריז, עם המיקום שלכם וזמני תורים חיים על הסמנים.
- **מקומות**: כרטיס לכל פריט, עם תמונה, הסבר בעברית, גובה מינימום, התאמה לפעוטות, רמת פחד, טיפים מהשטח ונתונים חיים.
- **לו״ז**: לו״ז אישי לכל יום, מסלול במפה, ושיתוף בקישור כדי שלשני ההורים יהיה אותו לו״ז.
- **רשימות**: צ׳קליסט (להזמין, לבדוק, לארוז), טיפים והגדרות (גובה הבנות).

## נתונים
- זמני תורים, מצב מתקנים, מופעים ושעות: [ThemeParks.wiki](https://themeparks.wiki), בזמן אמת מהדפדפן.
- מפה: © OpenStreetMap contributors. מזג אוויר: Open-Meteo.
- תמונות: Wikimedia Commons, ברישיונות חופשיים. הקרדיטים מופיעים בלשונית ״אודות״ באפליקציה.
